This is the home page. It is built using simple HTML and CSS with a subtle dark neon glow effect.

Neon Design is a visual styling technique inspired by glowing electrified gas tubes and cyberpunk aesthetics. It relies heavily on high contrast, using vibrant cyan, magenta, and purple tones against deep black or navy backgrounds. In modern web design, developers achieve this effect using CSS properties like text-shadow and box-shadow stacked in multiple layers to simulate radiated light. This design trend is popular for gaming portals, music platforms, and modern tech websites looking to create an energetic, futuristic atmosphere.
